# Programming fundamentals image sources

The lesson's three images are rasterized from these reusable source illustrations:

- `sudoku-iteration.webp`: “Sudoku Most Canonical grid” by Dobrichev, released under CC0 1.0. Source: https://commons.wikimedia.org/wiki/File:Sudoku_Most_Canonical_grid.svg
- `password-conditionals.webp`: “Secure Password” by unDraw. Used under the unDraw license, which permits free personal and commercial use without attribution. Source: https://undraw.co/illustration/secure-password_9qv4 · License: https://undraw.co/license
- `folders-recursion.webp`: “Files11 directory hierarchy” by Kate/User:Stannered, released into the public domain. Source: https://commons.wikimedia.org/wiki/File:Files11_directory_hierarchy.svg

The original SVGs were centered on a neutral background and exported as 900 × 550 WebP files for consistent lesson cards.
