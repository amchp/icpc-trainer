Application shell

  • Keep Resources active on nested routes.Browser Back returns to the roadmap.

05

Programming Fundamentals guide

Adapt all 46 slides into neutral Latin American Spanish. Teach transferable concepts through C++; do not turn the guide into a compiler setup course.

01 · Mental model

Programar es construir con bloques

Skills combine into systems; introduce the four core blocks.

02 · Representation

Representación y tipos

Bits, bool, int, double, and char.

03 · Operations

Operadores y conversiones

Arithmetic, modulo, comparisons, boolean logic, and casting.

04 · Branching

Condicionales

Boolean expressions and if / else if / else.

05 · Repetition

Iteración

for, while, boundaries, and termination.

06 · Reuse

Funciones

Parameters, return values, and tracing a call.

07 · Collections

Vectores y control de ciclos

Indexing, iteration, push_back, break, and continue.

08 · Calls

Recursión

Base cases and a factorial call-stack walkthrough.

06

Learning interactions

Author pure TSX and build a small reusable component vocabulary. Code is read-only, highlighted, copyable, and stepped through predetermined traces.

Interactive visuals

  • Representation explorerInspect how types hold values.
  • Conditional branch demoChange inputs and see the selected path.
  • Loop stepperTrack initialization, condition, body, and update.
  • Function and recursion demosTrace values and stack frames.

Practice and navigation

  • Immediate-feedback checksRetry freely; no completion gate.
  • Sticky horizontal progress railSection anchors and reading position only.
  • Accessible step controlsPrevious, next, reset, play/pause, and text summaries.
  • Completion footerComplete or return to in progress.
07

Public contracts

Validate guide IDs centrally. Unknown guides and unauthenticated requests fail before touching persistence.

ContractInputBehavior
learningProgress.listNoneReturn only the authenticated App User’s guide-level progress.
learningProgress.start{ guideId }Insert in progress if absent; remain idempotent; never downgrade completed.
learningProgress.setStatus{ guideId, status }Complete with server time, or return to in progress and clear completion time.
LearningGuideIdShared typeInitially only programming-fundamentals.

10

Scope guardrails

The first release proves one polished learning path. It deliberately avoids platform work that the blueprint does not need.

Included

  • One Spanish guide
  • Four interactive visual families
  • Manual reversible completion
  • Minimal milestone analytics
  • Responsive and reduced-motion support

Not included

  • Full curriculum
  • External resource archive
  • MDX authoring
  • Arbitrary C++ execution
  • Persisted quiz answers or section progress
  • Pan/zoom graph library
