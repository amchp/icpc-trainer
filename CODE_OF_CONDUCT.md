# Code of Conduct

ICPC Trainer contributors are expected to keep project spaces respectful, useful, and focused on the work.

## Expected Behavior

- Be direct, constructive, and considerate when reviewing code or discussing design.
- Assume good intent, but ask for clarification when something is unclear.
- Respect different levels of experience and different communication styles.
- Keep public issues and pull requests focused on reproducible facts, tradeoffs, and next steps.

## Unacceptable Behavior

- Harassment, threats, insults, or personal attacks.
- Discriminatory or sexualized language or imagery.
- Publishing someone else's private information without permission.
- Repeated off-topic comments, spam, or deliberate disruption.
- Dismissing security, privacy, or safety concerns without review.

## Enforcement

Maintainers may edit or remove comments, close issues, reject pull requests, or block accounts that violate this code of conduct. Serious issues should be reported privately to a maintainer. Security vulnerabilities should follow [SECURITY.md](SECURITY.md).
